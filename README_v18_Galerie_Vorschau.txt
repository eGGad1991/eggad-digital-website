Mila Website v18 – Galerie mit Bildvorschau

NEU:
- Desktop: Beim Darüberfahren über ein Galeriebild wird es weich vergrößert.
- Handy/Touch: Ein Tippen auf ein Bild öffnet eine große Vorschau.
- Die Vorschau lässt sich über das X, durch Tippen auf den dunklen Hintergrund oder mit Escape schließen.
- Funktioniert sowohl für die vorhandenen Bilder als auch für neu aus Supabase geladene Bilder.
- Das HubSpot-Kontaktformular aus v17 und die mobile Upload-/Login-Funktion bleiben erhalten.

DEPLOYMENT:
Diese Version basiert auf v17. Den gesamten Inhalt aus diesem ZIP wie gewohnt bei Cloudflare Pages als neue Produktionsversion veröffentlichen.

Hinweis: Die Galerie-Vorschau ist lokal im Paket geprüft (HTML-/JS-Struktur und JavaScript-Syntax). Ein Live-Test nach Cloudflare-Veröffentlichung ist noch erforderlich.
